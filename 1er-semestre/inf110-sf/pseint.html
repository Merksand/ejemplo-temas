¿Qué es un diagrama de flujo?
Es una representación gráfica de un algoritmo. Cada figura geométrica representa una operación distinta y las flechas indican el orden de ejecución.
PSeInt genera estos diagramas automáticamente desde el pseudocódigo — entender las formas es clave para leerlos e interpretarlos.

Formas y su significado

Óvalo / Terminal
Inicio o Fin del algoritmo. Siempre uno de cada uno.
Rectángulo
Proceso / instrucción. Asignaciones, operaciones.
Paralelogramo
Entrada / Salida. Leer o Escribir datos.
Rombo
Decisión. Condición con rama Sí / No.
Rectángulo doble
Llamada a subproceso / función / subalgoritmo.
Círculo / Conector
Conecta partes del diagrama que no caben juntas.

Ejemplo de diagrama — suma de dos números

① Inicio del algoritmo
② Pedir dato A al usuario
③ Pedir dato B al usuario
④ Calcular suma ← A + B
⑤ Mostrar el resultado
⑥ Fin del algoritmo

Las flechas indican el
orden de ejecución.
Reglas básicas de un diagrama de flujo
• Siempre empieza y termina con un óvalo
• Las flechas siempre apuntan en una sola dirección (no se pueden cruzar sin conector)
• El rombo (decisión) siempre tiene dos salidas: Sí y No
• Toda entrada o salida de datos usa el paralelogramo, no el rectángulo
Palabras reservadas en PSeInt
Son palabras que PSeInt ya entiende — no se pueden usar como nombres de variables.
PSeInt acepta variantes en español e inglés, pero acá usamos el perfil en español.

Estructura secuencial
Las instrucciones se ejecutan una tras otra en el orden en que están escritas.
No hay decisiones ni repeticiones — es el flujo más básico de un algoritmo.

Estructura base de un algoritmo

PSeIntPlantilla base
Algoritmo nombre_del_algoritmo
	// Declaración de variables (opcional pero buena práctica)
	Definir variable1 Como Entero
	Definir variable2 Como Real
	Definir nombre Como Caracter

	// Instrucciones
	Escribir "Mensaje al usuario"
	Leer variable1
	variable2 <- variable1 * 2.5
	Escribir "Resultado: ", variable2
FinAlgoritmo
Conversor de temperatura — Celsius a Fahrenheit secuencial
Fórmula: F = C × 9/5 + 32

Pasos:
1. Pedirle al usuario la temperatura en °C
2. Aplicar la fórmula de conversión
3. Mostrar el resultado en °F

Leer guarda el dato que escribe el usuario.
<- asigna el resultado del cálculo.
Las comas en Escribir concatenan textos y variables. 
Algoritmo ConversorTemp
  Definir celsius, fahrenheit Como Real

  Escribir "Ingresá temperatura en °C:"
  Leer celsius

  fahrenheit <- celsius * 9/5 + 32

  Escribir celsius, "°C = ", fahrenheit, "°F"
FinAlgoritmo

Área y perímetro de un rectángulo secuencial
Calcula dos resultados a partir de dos entradas.

Área = base × altura
Perímetro = 2 × (base + altura)

Una variable puede usarse en múltiples operaciones.
Podés definir varias variables del mismo tipo separadas por coma. 
Algoritmo RectanguloGeometria
  Definir base, altura, area, perim Como Real

  Escribir "Base del rectángulo:"
  Leer base
  Escribir "Altura del rectángulo:"
  Leer altura

  area  <- base * altura
  perim <- 2 * (base + altura)

  Escribir "Área:      ", area
  Escribir "Perímetro: ", perim
FinAlgoritmo
Si … Entonces
Rama simple. Ejecuta el bloque solo si la condición es verdadera.
Si … SiNo
Rama doble. Un camino si es verdadero, otro si es falso.
Si anidados
Si dentro de Si. Para condiciones en cascada o múltiples rangos.
Segun … Hacer
Múltiples casos exactos de una variable. Más limpio que Si anidados cuando hay muchas opciones.
Aprobación de materia (Si simple y Si/SiNo) condicional
Condición: aprueba si nota >= 51.

Si simple: solo hace algo si es verdadero.
Si/SiNo: hace algo en cada caso.

La condición puede usar Y, O, No para combinar. 
Algoritmo Aprobacion
  Definir nota Como Entero

  Escribir "Ingresá tu nota (0-100):"
  Leer nota

  Si nota >= 51 Entonces
    Escribir "¡Aprobaste!"
  SiNo
    Escribir "Reprobaste."
  FinSi

  // Con rango de notas (Si anidado)
  Si nota >= 90 Entonces
    Escribir "Excelente"
  SiNo
    Si nota >= 51 Entonces
      Escribir "Aprobado"
    SiNo
      Escribir "Reprobado"
    FinSi
  FinSi
FinAlgoritmo

Menú de opciones con Segun condicional
Segun es el equivalente al switch de otros lenguajes.

Cada bloque termina con una coma o con el separador implícito.
De Otro Modo es el caso por defecto (si ninguno coincide).

Ideal cuando tenés muchas opciones de un mismo valor en vez de Si anidados. 
Algoritmo MenuOpciones
  Definir opcion Como Entero

  Escribir "1) Sumar  2) Restar  3) Salir"
  Leer opcion

  Segun opcion Hacer
    1:
      Escribir "Elegiste Sumar"
    2:
      Escribir "Elegiste Restar"
    3:
      Escribir "Saliendo..."
    De Otro Modo:
      Escribir "Opción inválida"
  FinSegun
FinAlgoritmo
Mientras … FinMientras
Condición al inicio. Puede no ejecutarse ni una vez si la condición es falsa desde el principio. Usar cuando no sabés cuántas veces va a repetir.
Repetir … HastaQue
Condición al final. Se ejecuta al menos una vez siempre. Se repite mientras la condición sea falsa; sale cuando es verdadera.
Para … FinPara
Con contador. El más limpio cuando sabés exactamente cuántas iteraciones necesitás. El paso por defecto es +1.
Tabla de multiplicar con Para bucle Para
El contador i va de 1 a 10, incrementando de a 1.

Con Paso es opcional — por defecto es +1.
Para contar al revés: Para i <- 10 Hasta 1 Con Paso -1

El valor de i está disponible dentro del bloque en cada iteración. 
Algoritmo TablaMultiplicar
  Definir n, i Como Entero

  Escribir "¿De qué número?"
  Leer n

  Para i <- 1 Hasta 10 Con Paso 1 Hacer
    Escribir n, " x ", i, " = ", n*i
  FinPara
FinAlgoritmo
Acumulador de suma con Mientras bucle Mientras
Suma números que el usuario ingresa hasta que ingresa 0.

El acum arranca en 0 y se va sumando en cada iteración.
La condición se evalúa antes de entrar — si el primer número es 0, no suma nada.

Patrón común: inicializar acumulador → leer primero → bucle → mostrar resultado. 
Algoritmo SumaAcumulada
  Definir num, acum Como Real

  acum <- 0
  Escribir "Ingresá números (0 para terminar):"
  Leer num

  Mientras num <> 0 Hacer
    acum <- acum + num
    Leer num
  FinMientras

  Escribir "Suma total: ", acum
FinAlgoritmo
Validación de entrada con Repetir bucle Repetir
Repite hasta que el usuario ingresa un dato válido.

El bloque siempre se ejecuta al menos una vez — ideal para pedir datos obligatorios.
HastaQue sale cuando la condición es verdadera (al revés del Mientras). 
Algoritmo ValidarEdad
  Definir edad Como Entero

  Repetir
    Escribir "Ingresá tu edad (1-120):"
    Leer edad
    Si edad < 1 O edad > 120 Entonces
      Escribir "Edad inválida, intentá de nuevo."
    FinSi
  HastaQue edad >= 1 Y edad <= 120

  Escribir "Edad registrada: ", edad
FinAlgoritmo

¿Cuándo usar cada bucle?
Para → cuando sabés exactamente cuántas veces va a repetir (recorrer 10 elementos, generar tabla del 1 al 10)
Mientras → cuando la cantidad de repeticiones depende de una condición (el usuario decide cuándo parar)
Repetir → cuando necesitás que se ejecute al menos una vez (pedir datos con validación, mostrar menú hasta que elija salir)
Subproceso (Proceso)
No devuelve valor. Agrupa instrucciones con un nombre. Se llama escribiendo su nombre. Útil para tareas repetidas como mostrar un menú.
Función (Funcion)
Devuelve un valor con Retornar. Se puede usar en expresiones como si fuera una variable. El tipo del retorno va en la declaración.
Función que calcula el factorial función
La función recibe un parámetro n y devuelve el factorial.

Funcion resultado <- nombre(parametros) es la sintaxis.
resultado es el nombre que lleva el valor de retorno.

La función se llama desde el algoritmo principal como si fuera una variable en una expresión. 
Funcion resultado <- Factorial(n)
  Definir i, resultado Como Entero
  resultado <- 1
  Para i <- 2 Hasta n Hacer
    resultado <- resultado * i
  FinPara
FinFuncion

Algoritmo UsarFactorial
  Definir num, res Como Entero
  Escribir "Número para calcular factorial:"
  Leer num
  res <- Factorial(num)
  Escribir num, "! = ", res
FinAlgoritmo
Subproceso que muestra un separador subproceso
Un Proceso no retorna nada — solo ejecuta instrucciones.

Se define fuera del algoritmo principal y se llama por nombre.
Puede recibir parámetros o no.

Útil para no repetir código (DRY — Don't Repeat Yourself). 
Proceso MostrarLinea
  Escribir "========================"
FinProceso

Proceso Saludo(nombre)
  Escribir "Hola, ", nombre, "!"
FinProceso

Algoritmo PrincipalConSubprocesos
  Definir nom Como Caracter
  Leer nom
  MostrarLinea
  Saludo(nom)
  MostrarLinea
FinAlgoritmo
