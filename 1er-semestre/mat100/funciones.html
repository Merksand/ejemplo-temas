Funciones

Explora definición, tipos, dominio/rango, operaciones y clasificación

¿Qué es una función?
Una función f: A → B es una regla que a cada elemento del conjunto A (dominio) le asigna exactamente un elemento del conjunto B (rango).

La clave: un valor de entrada → un único valor de salida. Si un x produce dos y distintos, no es función.

Notación importante
f(x) se lee "f de x" y representa el valor de salida cuando la entrada es x.
f(3) = 7 → al darle 3 a la función, devuelve 7.
y = f(x) → y y f(x) son lo mismo, solo formas distintas de escribirlo.
¿Cuándo NO es función?
Si a un mismo x le corresponden dos o más valores de y, no es función.
Prueba visual: la prueba de la recta vertical — si una línea vertical toca la gráfica en más de un punto, no es función.
Ejemplo: x² + y² = r² (circunferencia) no es función.

Tipos de funciones — haz clic para ver detalles

Tip para identificar el tipo
Mira dónde está la variable x:
• En la base con exponente constante → polinómica (lineal, cuadrática, etc.)
• En el exponente → exponencial
• Dentro de un log → logarítmica
• Dentro de sin/cos/tan → trigonométrica
• Dentro de una raíz → radical / irracional
Dominio vs Rango
Dominio → todos los valores de x que puedo meter a la función (entradas válidas).
Rango → todos los valores de y que puede producir la función (salidas posibles).

Para hallar el dominio: buscás qué valores de x rompen la función (dividir entre 0, raíz de negativo, log de negativo) y los excluís.

Ejemplos con restricciones comunes

Restricciones a memorizar
1/f(x) → f(x) ≠ 0 (no se puede dividir entre cero)
√f(x) → f(x) ≥ 0 (no existe raíz de negativos en ℝ)
log f(x) → f(x) > 0 (log solo existe para positivos)
tan(x) → x ≠ π/2 + nπ (donde cos(x) = 0)
Operaciones entre funciones
Si tenemos f(x) = 2x + 1 y g(x) = x² − 3, podemos combinarlas.
El dominio de la operación es la intersección de los dominios de f y g.

Composición de funciones

¿Qué es la composición?
(f∘g)(x) = f(g(x)) → primero aplico g, luego le aplico f al resultado.
¡El orden importa! f∘g ≠ g∘f en general.

Función inversa
Solo existe si la función es biyectiva.
Se denota f⁻¹(x) y "deshace" lo que hace f.
Para encontrarla: despejás x en y = f(x), luego intercambiás x e y.
f(f⁻¹(x)) = x y f⁻¹(f(x)) = x
