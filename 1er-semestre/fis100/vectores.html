Vectores

Concepto, componentes, operaciones y productos vectoriales

¿Qué es un vector?
Es un ente matemático que necesita módulo, dirección y sentido para describirse completamente.
Un escalar solo es un número (temperatura, masa). Un vector es un número con rumbo.

Decir "la fuerza es 10 N" está incompleto → "10 N hacia la derecha a 30°" es un vector completo.

Elementos de un vector

Elemento¿Qué es?Fórmula / nota
Módulo |A| Tamaño o intensidad — siempre ≥ 0 |A| = √(Ax² + Ay²)
Dirección θ Ángulo con el eje x positivo, en grados o radianes θ = arctan(Ay / Ax) — verificar cuadrante
Sentido Hacia qué lado apunta la punta de la flecha Lo representa la punta de la flecha →
Punto de aplicación Desde dónde actúa el vector (importa en torques) El extremo de inicio de la flecha

Notación

Formas de escribir un vector
→A → flecha sobre la letra (notación manual)
A → negrita (en texto impreso)
A = (Ax, Ay) → notación por componentes
A = Ax·î + Ay·ĵ → notación con vectores unitarios
|A| o A (sin flecha) → solo el módulo, un escalar

Tipos según posición

Vector librelibre
Se puede trasladar en el espacio sin cambiar su significado. Solo importan módulo, dirección y sentido.

Ejemplo: velocidad, desplazamiento
Vector deslizantedeslizante
Solo puede moverse a lo largo de su línea de acción.

Ejemplo: fuerzas sobre cuerpos rígidos
Vector fijofijo
Tiene un punto de aplicación específico que no puede cambiar.

Ejemplo: fuerza en un punto de una estructura

Vectores especiales

Vector nulo|A| = 0
Módulo igual a cero. No tiene dirección ni sentido definidos.
A + (−A) = 0
Vector unitario|û| = 1
Módulo igual a 1 — solo indica dirección y sentido.
û = A / |A|
Vector opuesto−A
Mismo módulo y dirección pero sentido contrario.
A + (−A) = vector nulo
¿Por qué descomponer?
Trabajar con componentes es mucho más fácil que con ángulos directamente.
Cada componente es un escalar (puede ser + o −), y permite sumar vectores con álgebra simple.
Es la base de todo el cálculo vectorial analítico.

Fórmulas de descomposición en 2D

Componente X
Ax = |A| · cos(θ)
Proyección sobre el eje x.
+ si apunta a la derecha
− si apunta a la izquierda
Componente Y
Ay = |A| · sen(θ)
Proyección sobre el eje y.
+ si apunta hacia arriba
− si apunta hacia abajo
Módulo desde componentes
|A| = √(Ax² + Ay²)
Pitágoras aplicado al triángulo que forman las componentes y el vector.
Ángulo desde componentes
θ = arctan(Ay / Ax)
⚠ La calculadora da arctan en (−90°, 90°). Siempre verificar el cuadrante.

Vectores unitarios cartesianos

î  →  (1, 0, 0) — dirección x
ĵ  →  (0, 1, 0) — dirección y
k̂  →  (0, 0, 1) — dirección z
Notación con vectores unitarios
En 2D: A = Ax·î + Ay·ĵ
En 3D: A = Ax·î + Ay·ĵ + Az·k̂
Ejemplo: si Ax = 3, Ay = −4 → A = 3î − 4ĵ

Métodos para sumar vectores

Cola a puntagráfico
El segundo vector empieza donde termina el primero.
El resultante R va desde el inicio del primero hasta el final del último.
Funciona para sumar cualquier cantidad de vectores.
Paralelogramográfico
Los dos vectores desde el mismo punto (cola con cola).
Se completa el paralelogramo con paralelas.
El resultante es la diagonal. Solo funciona para dos vectores a la vez.
Método analíticoel más usado
Exacto (no depende de la precisión del dibujo).
Rx = Ax + Bx + ...
Ry = Ay + By + ...
|R| = √(Rx² + Ry²)
Resta de vectores
A − B = A + (−B) → es sumar A con el opuesto de B.
El vector −B tiene el mismo módulo que B pero sentido contrario.

Aplicaciones: Δr = rf − ri (desplazamiento)  ·  Δv = vf − vi (para aceleración)

Propiedades de la suma vectorial
Conmutativa: A + B = B + A
Asociativa: (A + B) + C = A + (B + C)
Elemento neutro: A + 0 = A
Elemento opuesto: A + (−A) = 0
Producto punto ·escalar
El resultado es un número, no un vector.
A · B = |A|·|B|·cos(θ)
Mide qué tanto "van en la misma dirección".
Producto cruz ×vectorial
El resultado es un vector, perpendicular a ambos.
|A × B| = |A|·|B|·sen(θ)
Su sentido se determina con la regla de la mano derecha.

Casos especiales del producto punto
θ = 0° (paralelos): A · B = |A|·|B| → valor máximo
θ = 90° (perpendiculares): A · B = 0 → si A·B = 0 y ninguno es nulo, son perpendiculares
θ = 180° (antiparalelos): A · B = −|A|·|B| → valor mínimo

Aplicación física: W = F · d = F·d·cos(θ) — el trabajo es el producto punto de fuerza y desplazamiento.

Producto cruz — regla de la mano derecha

Cómo determinar la dirección de A × B
Apuntar los dedos de la mano derecha en la dirección de A
Curvar los dedos hacia B pasando por el ángulo más pequeño
El pulgar extendido apunta en la dirección de A × B
Producto cruz en 2D y 3D
En 2D (resultado solo tiene componente z):
A × B = (AxBy − AyBx) k̂

Vectores unitarios y sus cruces:
î × ĵ = k̂  ·  ĵ × k̂ = î  ·  k̂ × î = ĵ
Al invertir el orden cambia el signo: ĵ × î = −k̂
Aplicaciones físicas del producto cruz
Torque: τ = r × F — perpendicular al plano de r y F, |τ| = r·F·sen(θ)
Momento angular: L = r × p = r × (m·v)
Fuerza magnética: F = q·v × B — los campos magnéticos curvan trayectorias porque la fuerza es perpendicular a v
Velocidad de rotación: v = ω × r
