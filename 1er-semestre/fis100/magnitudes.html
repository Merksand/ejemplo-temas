Magnitudes fundamentales — Sistema Internacional (SI)

¿Qué es una magnitud fundamental?
Son las 7 magnitudes base del Sistema Internacional. No se pueden descomponer en otras — el resto del mundo físico se construye a partir de ellas.
Cada una tiene una unidad oficial y un símbolo único.

Magnitudes derivadas

Selecciona una fundamental para filtrar
¿Cómo se forman?
Las magnitudes derivadas se obtienen combinando fundamentales con × / o potencias.
Por ejemplo: la velocidad es longitud / tiempo → m/s.
La fuerza es masa × longitud / tiempo² → kg·m/s² = N.
